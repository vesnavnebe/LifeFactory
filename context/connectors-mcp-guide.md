# Connectors + MCP — Инструкция по подключению

> Персональная инструкция на основе твоего профиля.
> Подключай когда перейдёшь на Claude Cowork или аналогичный AI с поддержкой коннекторов.

---

## Приоритет 1 — Подключить сразу

### Gmail
**Зачем:** читать входящие счета, уведомления об оплате, письма клиентов.
**Как:** Settings → Connectors → Browse → Gmail → Authenticate.
**Первый запрос:** "Что пришло в Gmail за последние 3 дня? Выдели важное по клиентам."

### Google Calendar
**Зачем:** смотреть расписание дня, ставить напоминания на привычки и дедлайны.
**Как:** Settings → Connectors → Google Calendar → Authenticate.
**Первый запрос:** "Как выглядит моя неделя? Что нужно подготовить?"

---

## Приоритет 2 — Подключить на второй неделе

### Notion
**Зачем:** хранить идеи, контент-план, базу знаний по вайбкодингу.
**Как:** Settings → Connectors → Notion → Authenticate.
**Использование:** скидываешь сырые идеи → AI структурирует в Notion.

### Google Sheets
**Зачем:** финансовый учёт — доходы/расходы по трём источникам.
**Как:** Settings → Connectors → Google Sheets → Authenticate.
**Шаблон таблицы:** [создадим когда подключишь]

## Приоритет 3 — MCP расширения

### Zapier MCP (8000+ приложений)
**Зачем:** автоматизации между сервисами без кода. Например: новое письмо в Gmail с суммой → автоматически в Google Sheets.
**Как подключить:**
1. Зайди на zapier.com → MCP Server
2. Выбери "Claude Cowork" как платформу
3. Настрой нужные actions (например: Gmail → Sheets)
4. Скопируй URL сервера
5. Claude: Connectors → Add MCP → вставь URL

### Apify MCP (парсинг без кода)
**Зачем:** мониторить тренды в нише рекламы, собирать идеи для Reels, анализировать конкурентов.
**Как подключить:**
1. Зарегистрируйся на apify.com → получи бесплатный API-токен
2. Browse connectors → Apify → вставь ключ
**Первый запрос:** "Найди топ-10 постов про Яндекс Директ за последний месяц."

## Блоклист (обязательно до включения Browser Use / Computer Use)

Добавь в настройки блоклист — сайты, куда AI не должен заходить:
- Банковские приложения и сайты
- Яндекс Директ кабинет (без твоего запроса)
- Личная почта (если отдельная от рабочей)
- Менеджеры паролей
