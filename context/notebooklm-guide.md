# NotebookLM — Как использовать для ресёрча

> notebooklm.google.com — бесплатно, без регистрации (нужен Google-аккаунт)
> Главное отличие: отвечает ТОЛЬКО по твоим источникам. Никаких галлюцинаций.

---

## Твои сценарии использования

### 1. Изучить вайбкодинг системно (главный сценарий сейчас)

**Шаги:**
1. Открой notebooklm.google.com → New notebook → "Вайбкодинг"
2. Добавь источники (кнопка + Sources):
   - YouTube-видео по vibe coding (вставь URL — транскрипт извлечётся автоматически)
   - Статьи и гайды (PDF или ссылки)
   - Этот воркшоп (можно скопировать тексты уроков)
3. Задавай вопросы:
   - "Что такое вайбкодинг и с чего начать?"
   - "Какие инструменты нужны для старта?"
   - "Какие продукты можно создать без опыта в коде?"
4. Генерируй Audio Overview — два AI-ведущих обсудят твои источники как подкаст 🎧

---

### 2. Подготовка экспертного поста или урока для клуба

**Шаги:**
1. Новый notebook → тема (например: "LAL-аудитории в Директ")
2. Добавь: скриншоты из кабинета, статьи Яндекса, кейсы
3. Попроси: "Сделай структуру поста на 400 слов по этим материалам"
4. Экспорт outline → сюда → `/write-post` для финального текста

---

### 3. Ресёрч ниши перед питчем клиенту

1. Notebook → ниша клиента (например: "косметика интернет-магазин")
2. Добавь: сайт клиента, топ-конкурентов, статьи по нише
3. Спроси: "Какие ключевые сегменты аудитории? Что важно для рекламы?"

---

## Системный ресёрч за 4 часа (воркфлоу Danny)

Когда изучаешь новую тему (например: вайбкодинг-инструменты):

1. **15 мин — фундамент:** спроси меня: "Кто топ-3 эксперта по вайбкодингу? Их ключевые материалы?"
2. **15 мин — загрузи в NotebookLM:** все найденные материалы в один notebook
3. **1-3 часа — перекрёстный допрос:**
   - NotebookLM: "Какие ключевые инструменты упоминают эксперты?"
   - Я (Copilot): "Найди логические дыры. Какие 3 вопроса задать глубже?"
   - Снова NotebookLM с новыми вопросами — повторяй спираль
4. **Итог:** структурированное понимание темы с реальными источниками

---

## Связка NotebookLM + я (вместо Claude)

- NotebookLM = "база без галлюцинаций" — только твои источники
- Я = критическое мышление, расширение, генерация контента
- Вместе = системное изучение любой темы

**Пример для вайбкодинга:**
1. Загружаешь видео и статьи в NotebookLM
2. Получаешь выжимку и цитаты
3. Скидываешь мне → я генерирую пост, план обучения или идею продукта
