# Working Preferences

## Формат вывода

- Всё в Markdown (.md)
- Код - в блоках с подсветкой синтаксиса
- Таблицы - markdown-таблицами
- Короткие абзацы, заголовки для структуры

## Именование файлов

Формат: `название_ГГГГ-ММ-ДД.md`
Пример: `пост-про-директ_2026-05-14.md`

## Plan Mode - обязательно

Перед любой задачей: покажи план, жди одобрения, потом выполняй.
Каждый этап завершай кратким отчётом: что сделано, что дальше.
Если задача большая - разбей на этапы.

## Запрещено без подтверждения

- Удалять файлы и папки
- Отправлять сообщения или письма
- Публиковать контент где-либо
- Перезаписывать файлы из папки context/
