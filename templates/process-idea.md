# Skill: /process-idea

## Активация
Используй команду: `/process-idea`

## Что делает
Оценивает сырую идею по критериям и перемещает из inbox/ в processed/ с карточкой.

## Входные данные
- Сырая идея (текст, голосовая транскрипция, скриншот)

## Алгоритм

1. Прочитай идею из my-ideas/inbox/ (или принят прямо в чат)
2. Оцени по 4 критериям (1-5):

| Критерий | Оценка | Комментарий |
|----------|--------|-------------|
| 🔥 Интерес (хочу ли я это делать?) | /5 | |
| 💰 Деньги (можно ли продать и за сколько?) | /5 | |
| ⚡ Скорость (MVP за сколько времени?) | /5 | |
| 🎯 Совпадение с целью (вайбкодинг/продукт?) | /5 | |

3. Итоговый балл: сумма / 20
4. Рекомендация: 
   - 16-20: 🚀 В работу
   - 10-15: 📋 В очередь
   - <10: 🗄 Архив

5. Создай файл `[название-идеи]_ГГГГ-ММ-ДД.md` в my-ideas/processed/
6. Добавь строку в my-ideas/ideas.md

## Формат карточки в processed/

```
# [Название идеи]

**Дата:** ДД.ММ.ГГГГ
**Балл:** X/20 — [статус]

## Суть
[1-3 предложения]

## Оценка
[таблица выше]

## Следующий шаг
[конкретное действие если берём в работу]
```
