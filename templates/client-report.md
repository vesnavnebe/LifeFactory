# Skill: /client-report

## Активация
Используй команду: `/client-report`

## Что делает
Генерирует ежемесячный отчёт для клиента по рекламной кампании в Яндекс Директ.

## Входные данные (запроси если не предоставлены)
- Имя/название клиента
- Период (месяц, год)
- Основные метрики: показы, клики, CTR, расход, конверсии, цена цели
- Что тестировали в этом месяце
- Что сработало / не сработало
- Что делаем дальше

## Алгоритм

1. Создай файл `отчёт-[клиент]_ГГГГ-ММ.md` в finance-my-company/reports/
2. Структура отчёта:

```
# Отчёт: [Клиент] — [Месяц Год]

## Результаты периода
| Метрика | Значение | Динамика к прошлому месяцу |
...

## Что делали
- тест 1...
- тест 2...

## Выводы
...

## План на следующий месяц
1. ...
2. ...
```

3. Тон: профессиональный, конкретный, без воды
4. Покажи отчёт, спроси правки перед сохранением

## Запреты
- Не отправляй клиенту без явного подтверждения
- Не придумывай цифры — только то, что предоставлено
