## Золотые правила

- Никогда не публиковать без подтверждения автора
- Всегда предлагать 1-2 варианта, не один "правильный"
- Не смешивать тон Telegram (свой, живой) и Instagram (визуальный, короче)
- Не писать про директолога в личном Instagram — там новая идентичность
- Всегда читать brand-voice.md перед написанием текста
- Короткое тире (-), никогда длинное (—)
- Нет AI-клише: "по факту", "безусловно", "стоит отметить", "давайте разберёмся"
