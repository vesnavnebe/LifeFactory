# my-ideas — Project Instructions

## Цель проекта

Собирать, оценивать и развивать идеи: вайбкод-продукты, личный бренд нового формата, автоматизации для бизнеса.

## Правила работы

- Формат файлов: .md, именование `идея_ГГГГ-ММ-ДД.md`
- Новые сырые идеи (из заметок, голосовых, избранного Telegram) → inbox/
- После оценки → processed/ с оценкой по критериям: интерес / деньги / время на MVP
- Список всех идей → ideas.md (пополняется)
- Всегда показывай план, жди одобрения

## Связь с профилем

- Два главных направления для идей:
  1. **Вайбкодинг** — продукты, инструменты, автоматизации, которые можно продать
  2. **Личный бренд** — не как директолог, а новая идентичность: вайбкодинг + лайф
- Telegram-агент на своём сервере — идея зафиксирована, разобрать как реализовать бесплатно
- Экспертиза в рекламе → кандидат для автоматизации и продуктизации

## Как оценивать идеи

При обработке идеи задай три вопроса:
1. Могу ли я сделать это через вайбкодинг?
2. Кто купит и за сколько?
3. Сколько времени займёт MVP?

## Активные идеи (зафиксированы)

- [ ] Личный бренд: новая идентичность вайбкодинг/лайф (не директолог)
- [ ] Telegram-агент на своём сервере — исследовать бесплатные варианты
- [ ] Автоматизации для МСБ на продажу

## Источники идей

- Голосовые заметки в Telegram «Избранное» (транскрибирует)
- Заметки в телефоне
- В будущем: агент в Telegram для быстрого захвата
