# content-reels — Project Instructions

## Цель проекта

Создавать контент для трёх площадок: Reels для школы (ежедневно), Telegram-канал «Реклама на Юпитере», новый личный Instagram — и строить новую идентичность: вайбкодинг + лайф, не только директолог.

## Правила работы

- Формат файлов: .md
- Черновики и сценарии → drafts/
- Готовые посты по платформам → outputs/ (подпапки: telegram/, instagram/, reels/)
- Референсы и примеры → references/
- Контент-план → calendar.md
- Стиль — всегда по brand-voice.md из этой папки
- Всегда показывай план, жди одобрения

## Связь с профилем

- Экспертиза в рекламе → основа экспертного контента
- Вайбкодинг как новое направление → строим новый голос и образ
- Тон: эксперт-подружка, живо, с юмором, короткое тире, без AI-клише

## Три площадки

### Instagram (Reels для школы)
- Почти ежедневно, рабочий аккаунт
- Формат: Reels → бесплатные уроки → воронка → покупка курса
- Тон: вовлекающий, лёгкий, зовущий посмотреть

### Telegram «Реклама на Юпитере»
- Экспертные посты + немного лайфа
- Сейчас редко (надоела тема рекламы) — будем разбавлять жизнью и вайбкодингом
- Цель: оживить канал новой темой

### Instagram личный (в процессе регистрации)
- Старый аккаунт с 2011 заблокирован — создаём новый
- Новая идентичность: НЕ директолог, а вайбкодинг + лайф
- Когда создаст — добавить сюда логин и стратегию
