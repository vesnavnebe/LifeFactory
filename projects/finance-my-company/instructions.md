# finance-my-company — Project Instructions

## Цель проекта

Вести личный учёт доходов и расходов, понимать финансовую картину и формировать инвойсы для клиентов.

## Правила работы

- Формат файлов: .md и таблицы (Google Sheets)
- Входящие чеки, счета, выписки → inbox/
- Отчёты (еженедельные/ежемесячные) → reports/
- Шаблоны (инвойс, P&L) → templates/
- Никогда не удалять финансовые документы без подтверждения
- Всегда показывай план, жди одобрения

## Связь с профилем

- Три источника дохода: клиенты на Директ / школа (наставничество + криэйтинг) / Telegram-канал
- Сейчас нестабильно — важно видеть реальные цифры
- Переход к вайбкодингу → нужна финансовая база для понимания «сколько нужно зарабатывать"

## Категории доходов

| Категория | Описание |
|-----------|----------|
| Клиенты Директ | Ведение рекламных кампаний для МСБ |
| Школа: наставничество | Оплата за роль ментора в клубе |
| Школа: криэйтинг | Оплата за Reels |
| Telegram-канал | Реклама, партнёрства |
| Прочее | Консультации, разовые |

## Категории расходов

| Категория | Примеры |
|-----------|----------|
| Сервисы и подписки | ChatGPT, инструменты, хостинг |
| Реклама | Продвижение личного канала |
| Обучение | Курсы, воркшопы |
| Прочее | |

## Формат учёта

- Личный учёт (без бухгалтера)
- Инвойсы клиентам по шаблону → templates/инвойс-шаблон.md
- Ежемесячный отчёт → reports/ по формату: доходы / расходы / прибыль / что изменить
