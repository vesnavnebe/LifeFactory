# Промпт-пак: 10 готовых запросов

_Скопируй промпт, заполни скобки своими данными, вставь в ChatGPT или Claude._
_Перед использованием убедись что AI уже знает твой голос (настройка в гайде, Шаг 2-3)._

---

## Промпт 1 — Пост в Telegram из одного тезиса

Используй когда: есть идея / наблюдение / мысль, хочешь быстро сделать пост.

```
Напиши пост для моего Telegram-канала.

Тезис: [одна фраза — суть поста]
Контекст: [2-3 предложения — откуда эта мысль, что за этим стоит]

Требования:
- Длина: до 600 символов
- Первое предложение — хук: провокация или боль, без вступления
- Без хэштегов
- Пиши в моём голосе как я его описала
- Дай 2 варианта — один провокационный, один мягче
```

---

## Промпт 2 — Сценарий рилса (30-45 сек)

Используй когда: нужен короткий видео-сценарий для Instagram или Telegram.

```
Напиши сценарий рилса на 30-45 секунд.

Тема: [тема]
Ключевая мысль которую хочу донести: [1 предложение]
Тип рилса: [образовательный / история / разоблачение мифа / лайфхак / POV]

Структура:
- ХУК (0-3 сек): одна фраза которую я говорю или текст на экране — провокация или боль
- РАЗВИТИЕ (3-35 сек): что показываю/объясняю — пошагово, коротко
- ФИНАЛ (35-42 сек): вывод одним предложением
- CTA: что написать в описании/комментах

Пиши текст который я буду произносить вслух. Разговорно, в моём голосе.
Без хэштегов. Без официоза.
```

## Промпт 3 — Идеи на неделю (батчинг)

Используй когда: не знаешь о чём писать, хочешь заготовить темы заранее.

```
Сгенерируй 10 идей для постов в мой Telegram-канал на следующую неделю.

Моя аудитория: [кто читает]
Последние темы которые я уже освещала: [3-5 тем — чтобы не повторяться]
Что сейчас актуально в моей нише: [что происходит в теме, тренды]

Для каждой идеи дай:
- Заголовок/тезис (1 строчка)
- Почему это зайдёт аудитории (1 строчка)
- Формат: пост / история / разоблачение мифа / кейс

Выдай список, без лишних объяснений.
```

## Промпт 4 — Ответ клиенту / подписчику

Используй когда: пришёл вопрос в личку или комментарии, нужно ответить быстро и по делу.

```
Помоги ответить на вопрос подписчика.

Вопрос: "[вставь вопрос дословно]"

Контекст: [коротко — кто спрашивает, что за этим стоит если знаешь]

Ответ должен:
- Быть написан в моём голосе
- Дать реальную пользу, не воду
- Длина: 3-5 предложений
- Если вопрос сложный — предложи следующий шаг (что им сделать дальше)

Дай 2 варианта: один короткий, один развёрнутый.
```

## Промпт 5 — Переписать плохой пост

Используй когда: написала сама, но чувствуешь что "не то", или слишком длинно/официально.

```
Перепиши этот пост. Он звучит [официально / скучно / слишком длинно / не как я].

Оригинал:
"""
[вставь свой текст]
"""

Что нужно улучшить: [что конкретно тебя не устраивает]
Что сохранить обязательно: [идея / факт / фраза которую нельзя убирать]

Перепиши в моём голосе. Сохрани суть, поменяй подачу.
Дай 2 варианта.
```

## Промпт 6 — Пост из голосового / заметки

Используй когда: наговорила в диктофон или записала мысль в заметки — нужно сделать из этого пост.

```
Вот мои необработанные мысли по теме — я наговорила как есть, без структуры.
Сделай из этого пост для Telegram.

Сырой текст:
"""
[вставь транскрипцию или необработанную заметку]
"""

Задача:
- Найди главную мысль
- Убери воду, оставь суть
- Напиши в моём голосе
- Длина: до 500 символов
- Без хэштегов

Дай 2 варианта: один с хуком-провокацией, один с хуком-вопросом.
```

## Промпт 7 — Серия постов из одной темы

Используй когда: хочешь сделать 3-5 постов на одну большую тему — чтобы разбить и не повторяться.

```
У меня есть большая тема: [тема]

Разбей её на 4 поста для Telegram которые будут выходить 4 дня подряд.

Требования:
- Каждый пост самодостаточен (можно читать без остальных)
- Вместе они раскрывают тему полностью
- Нарастающая глубина: от простого к сложному
- Последний пост — ведёт к действию / следующему шагу

Для каждого поста дай:
1. Тезис (1 строчка)
2. Краткое содержание (2-3 строчки)
3. Чем этот пост зацепит аудиторию

После одобрения — напишу каждый пост по отдельности.
```

## Промпт 8 — Подпись к рилсу (caption)

Используй когда: рилс готов, нужен текст под ним в Instagram или Telegram.

```
Напиши подпись к рилсу для Instagram.

О чём рилс: [1-2 предложения]
Главная мысль которую хочу донести: [1 предложение]
CTA (что должны сделать): [написать комментарий / перейти по ссылке / сохранить]

Требования:
- Длина: 80-150 символов (Instagram читают первые 2 строчки)
- Первое предложение — продолжает или усиливает хук из видео
- Без хэштегов
- В моём голосе

Дай 3 варианта.
```

## Промпт 9 — Анонс продукта / услуги

Используй когда: хочешь написать пост о том что продаёшь — без ощущения "рекламы".

```
Напиши анонс-пост о моём [продукте / услуге / интенсиве].

Что это: [название и суть — 1-2 предложения]
Для кого: [аудитория]
Главная польза: [что человек получит / что изменится]
Цена: [если указываешь]
Как купить / записаться: [ссылка или "написать мне"]

Подход: НЕ рекламный текст. Напиши как будто я рассказываю подруге о том что сделала — без пафоса, без "уникального предложения", без давления. Просто честно.

Длина: до 700 символов.
Дай 2 варианта: один от проблемы, один от результата.
```

## Промпт 10 — История из жизни → полезный вывод

Используй когда: что-то случилось, что-то заметила, что-то поняла — и хочешь сделать из этого контент.

```
Помоги написать пост-историю.

Что произошло: [опиши ситуацию — реальный случай, как есть]
Что я поняла из этого: [вывод / инсайт]
Для кого это актуально из моей аудитории: [кто узнает себя]

Структура поста:
- Открываемся с момента / детали которая цепляет (не "однажды я поняла...")
- Разворачиваем историю коротко
- Вывод который применим к читателю
- Финал: вопрос или призыв к рефлексии (необязательно)

Длина: до 700 символов. В моём голосе. Без пафоса.
```

## Бонус: промпт для итерации

Когда AI написал что-то близкое но не совсем — используй вместо того чтобы переделывать с нуля:

```
Хорошо, но нужно изменить:
- [что не нравится 1]
- [что не нравится 2]

Сохрани: [что обязательно оставить]

Перепиши только это, остальное оставь.
```

_Когда AI несколько раз пишет одно и то же "не ты" — добавь это в файл голоса в раздел "Я никогда не пишу". AI станет точнее._
